🚗 Verificador de Permissão para Dirigir

Este projeto é uma aplicação simples em Java que verifica se uma pessoa pode dirigir com base na sua idade e se ela é emancipada ou não.

📋 Funcionalidades

O programa:

Solicita o nome do usuário

Solicita a idade

Pergunta se o usuário é emancipado

Informa se a pessoa pode ou não dirigir, de acordo com as regras:

✔️ Maiores de 18 anos podem dirigir

✔️ Pessoas a partir de 16 anos emancipadas podem dirigir

❌ Caso contrário, não podem dirigir

🛠️ Tecnologias Utilizadas

Java (JDK 8 ou superior)

Classe Scanner para entrada de dados via terminal

▶️ Como Executar o Programa

Certifique-se de ter o Java JDK instalado

Salve o código no arquivo App.java

Compile o programa:

javac App.java


Execute o programa:

java App

💡 Exemplo de Execução
Informe seu nome:
João
Informe sua idade:
16
Você é emancipado? (s/n)
s
João, apesar de ter 16 anos, você é emancipado e pode dirigir.
Fim da execução

📌 Observações

A resposta para a pergunta sobre emancipação deve ser:

s para sim

qualquer outra letra será considerada não

O programa encerra automaticamente após a execução
